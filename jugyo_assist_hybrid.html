🔑 Gemini API キー 無料枠あり
取得方法：Google AI Studio を開く →「APIキーを作成」→ コピーして上に貼り付け
Googleアカウントだけで取得可能・クレジットカード不要・無料枠あり
🔑 OpenAI API キー
取得方法：OpenAI Platform を開く →「Create new secret key」→ コピーして貼り付け
※クレジットカード登録と初回チャージ（$5〜）が必要です。
🔑 Anthropic API キー
取得方法：Anthropic Console を開く →「Get API Keys」→「Create Key」→ コピーして貼り付け
※クレジットカード登録が必要です。初回$5の無料クレジットあり。
🗂 データ管理
データはブラウザ内のみに保存されます。端末外には送信されません（AI生成時のプロンプト除く）。
ℹ️ 授業アシスト β について
バージョン: 0.2.0-beta（AI ハイブリッド対応版）
データ保存: ブラウザ内 localStorage（端末外に出ません）
対応 AI: Gemini Flash / GPT-4o mini / Claude Sonnet
対応教科: 国語・数学・理科・社会・英語（実技教科は今後対応予定）
